# SFX & BGM Reference Guide

Organized by function and mood. Always verify audio is original, licensed, or platform-cleared before publishing.

---

## 🔊 SFX by Function

| SFX | Function | Placement |
|---|---|---|
| Camera shutter / click | Photo reveal | When photo appears |
| Vinyl crackle | Nostalgic texture | Under BGM intro |
| Whoosh / swipe | Transition emphasis | Mid-template transitions |
| Bass hit / 808 drop | Beat drop payoff | Key emotional moment |
| Glass / chime ting | Gentle accent | Soft emotional beat |
| Crowd / applause | Celebration, hype | Payoff moment |
| Wind / nature ambient | Travel, outdoor | Background texture |
| Notification ping | Relatable, Gen Z humor | Comedic beat |
| Heartbeat | Tension, anticipation | Before big reveal |
| Film reel / projector | Vintage, memory | Intro / transition |

## ⚠️ Audio Licensing Notes

- Use **CapCut's built-in licensed music library** as the primary source.
- If using external BGM, verify Creative Commons / royalty-free license.
- Never use copyrighted commercial tracks without sync license.
- Original voice recordings you produce yourself are always safe to use.
- SFX from CapCut's built-in library are platform-cleared for template publishing.
