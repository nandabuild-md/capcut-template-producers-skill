# Voice Signature Style Guide

This file defines the creative identity for all spoken-word lines, whisper overlays, and chill raps used in your CapCut templates. Use the Gemini prompt below every session.

---

## 🎙️ Voice Identity

| Dimension | Spec |
|---|---|
| Language | English (natural, US/global) |
| Tone | Calm, cinematic, intimate, slightly confident |
| Energy | Late-night diary / soft realization / quiet flex |
| Format options | Spoken word · Whisper overlay · Chill rap (2–4 bars) · Warm narration |
| Length | 8–18 words for spoken lines; 4–8 bars for chill rap |
| Key feeling | Should feel personal, not branded |

---

## 🎯 Signature Lanes & Voice Pairing

| Lane | Mood | Voice format | Example phrasing style |
|---|---|---|---|
| **Midnight Memoir** | Dark, nostalgic, reflective | Whisper / soft spoken | "I keep coming back to moments I thought I'd forget." |
| **Soft Flex** | Confident, cool, low-key luxury | Chill rap / spoken word | "Moving quiet, still getting everything I asked for." |
| **Memory Film** | Warm, nostalgic, bittersweet | Warm narration | "This is the version of us I'll always keep." |
| **Weekend Escape** | Free, adventurous, light | Spoken word / ambient | "Somewhere between here and there, I found the right pace." |

## ✨ Gemini Voice Generation Prompt

Copy this prompt into Gemini. Fill in `{{mood}}`, `{{theme}}`, and `{{format}}` before using.

```
Create an original, short English spoken-word line for a CapCut video template.

Template mood: {{mood}}
Template theme: {{theme}}
Voice format: {{format}}  ← Options: spoken word / whisper / chill rap / warm narration
Target audience: Gen Z and young millennials in the US and global English-speaking market
Voice identity: calm, cinematic, intimate, slightly confident, late-night diary energy
Duration: 3–7 seconds when spoken aloud

Rules:
- Write one original line only (or 2–4 bars if chill rap)
- 8 to 18 words maximum for spoken lines
- Avoid famous quotes, song lyrics, clichés, and brand references
- Make it suitable as an overlay for a photo/video montage
- End with a memorable emotional word or strong image
- Do not use explicit content

Return:
1. Final voice line (or rap bars)
2. Delivery direction: whisper / soft spoken / chill rap / warm narration
3. Suggested pause markers using "/"
4. Suggested timestamp placement in a 15–24 second template
5. One alternate version with slightly different energy
```
