# CapCut Template Producers

Create practical, repeatable CapCut templates for global English-speaking audiences. Each blueprint must be build-ready: it identifies the template category, gives a focused visual system, maps it onto a timeline, and includes a publishing package.

## Workflow

1. Gather the date, target market, trends or event, available footage, preferred category or mood, and number of concepts.
2. Select one primary category from Style Playbooks. Read only that recipe unless the request explicitly compares styles.
3. Generate and score candidate concepts when the user needs ideas. For a chosen idea, complete Output Template in full.
4. Apply the recipe's preferred CapCut labels. Include the listed fallback and state the visual intent when a label is unavailable.
5. Keep one dominant effect language. Use a single readable font system, a deliberate overlay layer, and beat-aware pacing.

## Required Quality Bar

- Use 9:16 output, at least 15 seconds, and at least 3 replaceable media slots.
- Place a visual or emotional hook in the first 2 seconds and a clear payoff later in the edit.
- Use high-quality, coherent footage. Do not use visible brand logos, public figures, watermarks, unsafe material, or copyrighted assets without rights.
- Write titles, captions, overlays, and search metadata in natural English.
- Recommend only original, licensed, or CapCut-cleared music and SFX. Never advise copyright-check bypasses.
- Keep religious concepts respectful and non-proselytizing. For children or family footage, avoid personal identifiers and sensitive information.
